## ✦ Visão

Este repositório é o núcleo backend da aplicação **API**: uma base Kotlin pensada para evoluir com clareza, velocidade e segurança.

> **Build the future. One endpoint at a time.**

## ⚡ Stack tecnológica

- **Kotlin** — linguagem principal, expressiva e type-safe
- **Arquitetura modular** — preparada para crescer sem perder legibilidade
- **API-first** — contratos claros entre cliente e servidor
- **Automação** — fluxo de desenvolvimento pronto para integração contínua

## 🚀 Começando

### Pré-requisitos

- JDK 17+ (ou a versão definida no projeto)
- Git
- Gradle Wrapper incluído no repositório

### Clonar e executar

```bash
git clone https://github.com/saraivasilva2204-commits/API.git
cd API

# Linux/macOS
./gradlew build
./gradlew run

# Windows
./gradlew.bat build
./gradlew.bat run
```

> Caso o projeto utilize uma task de execução diferente, confira as tasks disponíveis com `./gradlew tasks`.

## 🛠️ Fluxo de desenvolvimento

```bash
# Verificar o projeto
./gradlew check

# Executar os testes
./gradlew test

# Gerar o build
./gradlew build
```
